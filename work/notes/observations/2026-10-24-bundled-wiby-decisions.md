# Decisions made while building bundled-wiby-wikipedia (2026-10-24)

Recorded for the `bundled-wiby-wikipedia` done record. The code-site ones are written in full where they apply; this note is the index.

1. **Wikipedia not bundled; Wiby ships alone.** The default chain is `["mwmbl", "marginalia", "wiby"]`. The Wikimedia API Usage Guidelines require the User-Agent policy, which forbids copying a browser's User-Agent for automated clients; strict impersonation does exactly that, and is not weakened. Alternative considered: a `fetch` with an `Api-User-Agent` author header, rejected (the User-Agent is still a browser's). Full write-up: `2026-10-24-wikipedia-user-agent-policy.md`. Sites: header of `packages/webveil/src/core/backends/searchcast.ts` ("task bundled-wiby-wikipedia"), the changeset. Touches: the owner may want to ask the Wikimedia Foundation for a clarification.
2. **Wiby's attribution term is met in the snippet.** Wiby's JSON API terms say "Provide a link to wiby.me with the results". The result shape has no source field, so every Wiby result's snippet ends with `(via Wiby, https://wiby.me/)` (or is just `via Wiby, https://wiby.me/` when Wiby gives no text). User-visible, Wiby results only. Alternatives considered: a new `source` field on `SearchResult` (touches every backend, the MCP and pi output: out of scope); attribution in the docs only, as for the CC BY-NC-SA engines (does not meet a term that asks for the link "with the results"). Site: `ATTRIBUTION` in `packages/webveil/recipes/wiby.mjs`.
3. **`wiby.mjs` is webveil's own, not a searchcast copy.** searchcast has no Wiby example, so the header records the documents it was written from (URLs, date read, terms) instead of a searchcast commit. The test that checks a 40-hex searchcast commit now covers only the two copies; a new test checks the Wiby header names its documents and terms. Site: `packages/webveil/test/default-backend.test.ts`.
4. **Wiby's strings are HTML-decoded and whitespace-collapsed.** Wiby's server fills its JSON from a Go `html/template`, so titles and excerpts arrive HTML-escaped (`&#34;`, `&amp;`). `Snippet` (the query-centred excerpt Wiby's own page shows) is preferred, `Description` the fallback. One page only (at most 12 results), cut to `maxResults`; `&nsfw` is not sent. Site: `packages/webveil/recipes/wiby.mjs`.
5. **HTTP 503 from Wiby counts as `blocked`**, as in `mwmbl.mjs`, so an overloaded service cools down instead of being retried at once. Wiby documents no rate limit; this is a defensive choice. Site: same file.
6. **`text-rules.mjs` `APPROVED_ENGINES` lists Wiby and Wikipedia** (both owner-approved names), though only Wiby is bundled. The list is informational (the check is a denylist), so nothing else changes.
